# CIBERSEGURIDAD / CYBERSECURITY

## 🇪🇸 Español

Repositorio con ejercicios resueltos y recursos orientados a la práctica de ciberseguridad ofensiva. Su objetivo es servir como entorno de aprendizaje para desarrollar habilidades de pentesting, análisis de vulnerabilidades y técnicas de **Red Team**.

### Contenido
- Ejercicios resueltos.
- Laboratorios de pentesting.
- Técnicas de explotación.
- Escalada de privilegios.
- Enumeración y reconocimiento.
- Herramientas y scripts de apoyo.
- Write-ups y documentación.

> **Aviso:** Todo el contenido está destinado exclusivamente a fines educativos y de investigación. Utilízalo únicamente en entornos autorizados.


## 🇬🇧 English

Repository containing solved exercises and resources focused on offensive cybersecurity. Its purpose is to provide a learning environment for developing skills in penetration testing, vulnerability assessment, and **Red Team** techniques.

### Contents
- Solved exercises.
- Pentesting labs.
- Exploitation techniques.
- Privilege escalation.
- Enumeration and reconnaissance.
- Supporting tools and scripts.
- Write-ups and documentation.

> **Disclaimer:** All content is intended for educational and research purposes only. Use it exclusively in authorized environments.
